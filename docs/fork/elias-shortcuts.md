# Elias Premiere keyboard preset

Select **Elias Premiere (AZERTY)** in Edit → Keyboard Shortcuts. This preset ships
in the fork on macOS and Windows; existing active presets remain unchanged.

Translated from Elias’s own `3_09_2025_PR_SHORTCUTS.kys` (Premiere Pro 2025),
not from Adobe application code or bundled assets. No Adobe preset file is shipped.
Command becomes Control on Windows; the personal Control+W / Control+Shift+W
Undo/Redo bindings take precedence over Close Panel/Project there.
AZERTY punctuation/number-row shortcuts use explicit physical key positions;
letter shortcuts remain logical. The Windows build has not been exercised on a
physical Windows keyboard. On QWERTY these positional shortcuts keep their positions,
not their AZERTY printed labels.

270 mapped source bindings (plus a Mac ISO-key alias). The following 39 assigned source entries are not translated because the target command/context is not exposed, or the workspace identity is unknown. Unassigned source entries are ignored. Existing defaults for unmapped commands remain available.
